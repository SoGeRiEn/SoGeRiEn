# local-tools-ftp-sync

## Назначение
Единый навык для деплоя через MCP FTP-инструменты.

## Инструменты
- `ftp_config_show` - показать текущий конфиг
- `ftp_config_save` - сохранить патч конфига в `profiles.<profile>`
- `ftp_connect_test` - проверить подключение
- `ftp_remote_tree` - посмотреть дерево на сервере
- `ftp_upload` - загрузить один файл
- `ftp_download` - скачать файл

## Рабочий порядок
1. Проверить, что конфиг в формате `local_tools_ftp_multi_v1` и выбран нужный `profile`.
2. Проверить `local_dir` и `remote_dir` целевого профиля.
3. Запустить `ftp_connect_test` с тем же `profile`.
4. Выполнить `ftp_upload` с `local_path`.
5. `ftp_upload` сам вычисляет удаленный путь из `local_dir -> remote_dir`.
6. Коротко проверить результат (`ftp_remote_tree` или точечный `ftp_download`).

## Когда применять
- Любая задача, где после локальных правок нужен деплой.
- Любая задача, где нужно проверить содержимое удаленной папки проекта.
